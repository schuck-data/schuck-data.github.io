Tools

Built to make ideas tangible.

Small, free interactive tools from the Schuck Data workbench — the kind of thing we make to turn an abstract idea into something you can see and touch.

epiphany

The Normal distribution as a living stained-glass window. Drag the mean, spread, skewness and kurtosis and watch a statistically rigorous object render itself in glass — with optional value labels, equal-volume quantile sections, and a high-contrast mode.

QR Generator

Generate and download QR codes entirely in your browser. Nothing is uploaded — the code is built on your own machine and saved as an SVG or PNG, captioned with its contents.
