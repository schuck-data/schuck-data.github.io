Color workshop — Schuck Data

Four palette directions. Each shown in light and dark mode with the accent color used for the heading and primary button. Contrast ratios measured against the background — WCAG 2.0 AA / Section 508 requires 4.5:1 for normal text, 3:1 for large text and UI components. All eight variants below pass AA for the accent color.

1. Deep Ink Blue

Conservative, premium, trustworthy. The "blue chip consultancy" register — closest to traditional B2B but with modern weight. Accent is dark enough on light mode to feel substantial; the light variant in dark mode reads almost luminous.

3. Forest Green

Distinctive — almost nobody in this niche uses green. Connotes "growth," "clean," "organic" — works subtly in your favor when the topic is data quality. Risk: can read as a fintech/sustainability company if overdone, so the rest of the design needs to be data-flavored to anchor the message.
