Typography workshop — Schuck Data

Four type directions, each rendering the same homepage-style content. Look at how the headlines feel, how the body reads at a glance, and whether the overall personality fits a data consultancy. All four meet the Section 508 / WCAG 2.0 AA contrast bar — the choice here is about character, not legibility.

Option 1

System sans

-apple-system, Segoe UI, Roboto, ... 0 font downloads · instant
Use whatever sans-serif the visitor's operating system provides. macOS gets San Francisco; Windows gets Segoe UI; Android gets Roboto. Pragmatic and zero-cost — but the site looks subtly different on every platform, and on Windows specifically you inherit Segoe's slightly older feel. Defensible choice for a small business site; sets a low bar for brand distinctiveness.

Option 2

Inter

Inter (Google Fonts, variable) ~25 KB · 1 request
The default modern web sans. Designed by Rasmus Andersson for UI use — neutral, highly legible at small sizes, supports OpenType features like contextual alternates and tabular numerals (useful for displaying data). Used by Mozilla, GitHub Issues, Notion, Figma marketing, and roughly half of all B2B SaaS. Safe in the way "everyone reads it without noticing" — which is exactly what good UI type should do.

Option 3

IBM Plex Sans + Plex Mono

"IBM Plex Sans", "IBM Plex Mono" ~45 KB · 1 request
IBM's open-source corporate typeface. More personality than Inter — slightly more humanist, recognizable terminals, less anonymous. The Mono companion (used here for the eyebrow label) reinforces a "technical, engineering" brand register without going full developer-tool. Strong choice if you want to signal "we work with engineering teams" without it feeling like a startup.

Option 4

Fraunces (headings) + Inter (body)

"Fraunces" + "Inter" ~55 KB · 2 requests
Editorial serif headings with a clean sans body. Fraunces is a contemporary serif inspired by 1970s commercial type — confident, distinctive, slightly soft. Pairs the gravitas of a serif with the legibility of Inter for running text. Higher brand differentiation than the all-sans options, with a "we take this seriously" register. Reference: Stripe Press, some consulting and editorial brands. Risk: serifs can feel formal — your call whether that's a feature.
